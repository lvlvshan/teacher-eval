## 1. 系统定位与术语

### 1.1 系统要解决什么

学校每年使用一次「教职工满意度调查」，本系统让**学生每月对**「班级 × 课程 × 教员」**匿名打分**，后台自动汇总（每题当月平均分、维度均分、总分），导出成 Excel，老师/教务据此评优评教。

- 一个学期 ≈ 12 个月。每个「月」对应一个测评周期。
- 一个学校（单校区），**不区分校区**字段。

### 1.2 术语表

| 术语 | 含义 |
| --- | --- |
| 测评周期 | 以月为单位的一次测评（状态：进行中 / 已截止 / 已归档） |
| 班级 | 学生班级（含年级） |
| 课程 | 被教的课程名称 |
| 教员 | 被测评的老师 |
| 测评对象 | **（班级，课程，教员）** 三元组，决定要不要打分 |
| 场次 | 班级在机房的固定时段（可选；不排场次则全周期内可随时答） |
| 班级网段 | 创建测评时为班级填写的 CIDR，学生首页按它自动识别可参与的调研 |
| 会话 | 学生（同一台电脑浏览器）的匿名作答会话 |
| 提交 | 一次答完整题（20 题量表 + 可选开放题） |
| flag | 提交质量标记：`ok` 正常、`timeout` 超时、`fast` 过快、`uniform` 同分 |
| 维度 | 问卷大类（如：教学 / 服务 / 环境…） |
| 总分 | 20 题之和，满分 100 |

### 1.3 评分量表

1~5 分：**1 = 很不满意，2 = 不满意，3 = 一般，4 = 满意，5 = 很满意**。总分 = 20 题得分之和（满分 100）。

## 2. 学生 / 参与者使用说明

### 2.1 准入条件

使用前确认：

- 学校内网（管理员在创建测评时为班级填写了本班 IP 段；默认放行演示网段）。
- 本月测评周期处于「进行中」。
- 你的 IP 命中某个班级的 IP 段（在创建测评时或「名单」页填写）。
- 如排了机房场次，需在对应场次时段内作答；
- **班级 IP 段同时决定首页展示哪些班级的调研**：一个网段可以绑定多个班级，学生首页会把这些班级都列出来。

未满足时会有专门提示：

- IP 不在允许范围 → 「当前网络不在允许范围内（IP），请在本校机房内打开。」
- IP 未绑定班级 → 「当前网络（IP）还没有绑定班级，请联系管理员确认 IP 段配置。」
- 周期已截止 → 「本期测评已于 … 结束。」
- 有场次但不在该班时段 → 「本班测评时段为 …，请按时参加。」
- 已归档 → 「本期测评已归档，通道关闭。」

### 2.2 进入系统

1. 打开浏览器，访问统一地址（如 `http://<校园网地址>/`），**无需班级码、无需登录、无需扫码**。
2. 首页会按你的 IP 自动列出**可参与的全部班级调研**：
   - 只匹配到一个班级时，自动进入该班教员列表；
   - 匹配到多个班级（同网段多个班）时，点选自己的班级即可；
   - 一个都没有时，说明该网段还没绑定班级，请联系管理员。
3. 落到本班的「测评对象」列表：
   - 显示本班本月需要评价的教员（按班级 + 课程分组，可多组/多门课）。
   - 已完成 → 显示「已提交」；未完成 → 显示「开始评价」。
   - 显示本次作答倒计时（到期自动提交，标记为「超时提交」）。
   - 已完成所有对象后显示完成页。

### 2.3 开始作答

1. 点击「开始评价」，进入 20 题打分表单 + 可选开放题。
2. 评分方式：
   - 页面上的笑脸（😢 ~ 😄）直接点击选择，笑脸越开心分值越高；
   - **键盘**：直接按 `1`~`5` 打分（对应 😢~😄），`↑/↓` 或 `←/→/Enter` 切换上一题/下一题；
   - **打分选项按分值着色**：选中时背景随分值变化（1 红 / 2 橙 / 3 黄 / 4 绿 / 5 深绿），便于快速辨认分值；
3. 每题提交时自动保存本地草稿（localStorage），**刷新页面不丢**；**提交后不可修改**。
4. 未完成前可以切题、撤销草稿；切题后自动保存。
5. 时间到（`min(30 分钟, 场次剩余)`）后**自动提交**，标记 `timeout`，仍计入统计。

### 2.4 提交

- 必须**全部 20 题**都打过分（打散提交会被拒绝）。
- 开放题两个任选填写（每题 ≤ 1000 字，超长截断；空则不记）。

### 2.5 提交成功 / 去重

- 提交成功页 `/c/{班级id}/done/{对象id}` 提示已收到。
- 同一台设备对同一份问卷只能提交一次；再次提交会被服务端拦截：「重复提交：该问卷已由本设备提交过，请勿重复作答」。
- 设备识别采用「IP 哈希 + 浏览器 UA 哈希」，不采集姓名、学号；不再于浏览器端收集 MAC（浏览器本身也无法读取），服务端会按 IP 尝试从 ARP 邻居表取得同一机房内设备的 MAC，仅供管理员在「投票详情」中核查。

### 2.6 参与者应知的几件事

- 全程匿名：不收集姓名、学号；答题时不要求任何身份信息。
- 提交记录会保存完整 IP、浏览器 UA，以及服务端按 IP 从 ARP 表取到的 MAC（跨网段时为空）；这些信息仅管理员可在后台「投票详情」查看，Excel 导出只使用 /24 掩码。
- 请如实作答；20 题都打成同一分会被标记 `uniform`，作答太快（< 20 秒）会被标记 `fast`。异常标记默认仍计入统计，仅在后台提示。

## 3. 教师端使用说明

教师通常只是被测对象：

1. 被管理员纳入「班级 × 课程 × 教员」名单后（状态 `required` / `optional` / `excluded`）。
2. 被老师评价后，如需对照：后台导出「教员年度得分表 / 汇总包」中的**该教员维度**查看。
3. 开放题反馈（优点/意见）在汇总包「优点与建议」页单独查看。
4. 异常答卷（`uniform`/`fast`）默认已计入；若确认是脏数据，由教务在后台「明细」页剔除后重新导出。

## 4. 后台管理员使用说明

### 4.1 登录

- 地址：`http://<服务器>/admin`
- 初始账号 `admin / admin123`（**首次登录后务必改密**：`php think admin:password admin <新密码>`）。

### 4.2 看板

- 展示：计入提交数、异常提示数、各教员均分（满分 100）等。
- 异常提示 = 已计入统计但带 `fast` / `uniform` 标记的提交，仅作提醒。

### 4.3 基础数据维护

- **教员**：员工编号、姓名、性别、学科、科室、启用状态。
- **班级**：名称、年级、状态。
- **课程**：课程名称、课程编码。

> 测评对象在创建周期时直接指定「教员 + 班级 + 课程」，无需事先维护任课关系。

### 4.4 IP 段（创建测评时填写）

- 不再单独维护 IP 段：新建周期时选择班级后，直接填写**本班 IP 段**（CIDR，可多个，逗号或换行分隔；也支持单个 IP）。
- 一个班级可以填多个网段；同一网段也可以分别填到多个班级，学生首页会看到这些班级的调研。
- 创建后仍可在「名单」页按班级修改 IP 段；留空保存表示清空该班网段。
- 学生打开首页时，系统按其 IP 匹配这些网段，自动进入对应班级。
- 归档时这些 IP 段会一起写入归档快照（只读，超管可解冻后调整）。

### 4.5 测评周期与测评对象

- **新建周期**（如某月）：
  1. 设置年月/名称、开始时间、结束时间。
  2. 选择「教员 + 班级 + 课程」，填写**本班 IP 段**，点击「创建并开始测评」。
  3. 保存后立即开始，并自动生成问卷与班级名单；后续可在「名单」里继续添加测评对象、调整各班 IP 段。
- **状态流转**：`进行中 → 已截止 → 已归档`。
  - `进行中` 期间可添加/修改名单、排场次、改问卷，管理员可随时点「结束问卷」截止；
  - 到期由计划任务自动转 `已截止`（`php think period:switch`，crontab 每 5 分钟执行）；
  - 截止后在「汇总」查看结果并导出；月末归档（超管操作），归档后严格只读。
- **名单**：可标记 `必评 / 选评 / 不参评`，不参评需填原因。
- **场次**：可选；给班级排机房（机房、起止时间）。排场次后该班只能在该时段内作答；未排场次则全周期可答。

### 4.6 问卷

- 每次周期独立的问卷；默认按 docx《15.学员满意度调查表》生成 4 维度 × 5 题（20 题）+ 2 道开放题。
- 可维护题干、维度、题目顺序、分值、权重、开放题启用开关。

### 4.7 学生入口（按 IP 自动识别班级）

- 学生统一访问 `http://<服务器>/`，不需要班级码、登录或扫码。
- 系统按学生 IP 匹配**创建测评时为班级填写的 IP 段**，首页列出其可参与的全部班级调研：
  - 命中 1 个班级 → 自动进入该班教员列表；
  - 命中多个班级 → 首页展示班级列表，学生选择本班；
  - 命中 0 个 → 提示联系管理员确认该班 IP 段。
- 排错时检查对应周期「名单」页里该班填写的是否为机房网段。

### 4.8 提交明细

- 筛选：按周期、按班级、按教员、按 flag 过滤。
- flag 含义与计入口径：
  - `ok`：正常提交 → 计入。
  - `timeout`：超时自动提交 → 计入。
  - `fast`：作答时长 < 20 秒 → 默认计入，仅提示。
  - `uniform`：20 题同分 → 默认计入，仅提示。
- 「剔除」：确认是脏数据后置 `excluded = 1`，该条退出统计；「恢复计入」置 `excluded = 0` 重新纳入。
- `reviewed` 只表示管理员处理过，不再决定是否计入。

### 4.9 投票详情

- 入口：后台菜单「投票详情」，按周期查看，可叠加班级、教员、课程、状态、关键字（IP / MAC / 设备号）筛选。
- 「一台设备 ≈ 一名学生」：机房电脑以 IP + UA 指纹生成设备号（如 `A3F91C2D`）；列表按设备汇总提交份数、涉及班级/教员、最近提交时间，并在下方展开该设备的每一份提交。
- 每份提交可点「详情」查看：
  - 提交环境：明文 IP、/24 掩码、MAC（ARP）、浏览器 UA、提交时间、作答耗时、状态标记；
  - 逐题得分：按维度排序列出每道评分题的得分与满分；
  - 开放题原文：原文展示，不进入汇总统计；
  - 同一设备在本周期的其他提交，便于核对一人是否评了多位教员。
- **MAC 限制**：浏览器无法读取 MAC；服务端读取 ARP 邻居表，只有服务器与机房电脑处于同一二层网段才能取到真实 MAC，跨网段/代理/NAT 显示「—」。因此 MAC 为空不代表异常。
- 该页面仅管理员可见，查看行为会写审计日志；导出仍只用掩码，不导出明文 IP/MAC。
- 剔除按钮与「明细」页共用：异常记录（`fast` / `uniform`）默认计入，确认是脏数据时可在此剔除，之后也可恢复计入。

### 4.10 导出

- **单个教员年度表**：按教员 +（可选课程）导出 xlsx：A 列分类、B 列事件，C~N 列 = 1~12 月均分，A23=总分、A24=参评人数。
- **全部教员年度表 ZIP**：每个教员一份年度表，打包下载。
- **年度汇总包**（xlsx，7 页）：
  1. 汇总：月 × 教员/班级维度均分；
  2. 明细：单条提交的分值；
  3. 分布：1~5 分分布；
  4. 趋势：跨月变化；
  5. 场次：各班/场次实交与时间；
  6. 优点与建议：开放题按教员/班级归纳；
  7. 配置存档：周期/IP/问卷快照与哈希。

> 导出文件写入 `runtime/export/`，支持下载（含 `with_archive` 开关）。

## 5. 数据导出结果如何使用

### 5.1 统计口径（重要）

- 统计单位：**单校区**，不跨校区。
- 每题当月平均分 = 当月该题计入答卷的平均。
- 维度均分 = 维度内题目平均的算术平均。
- 总分 = 20 题得分之和（满分 100）。
- 计入答卷 = `excluded = 0` 的全部提交；异常标记（`fast` / `uniform` / `timeout`）默认也计入。

### 5.2 开放题单独呈现

「优点与建议」工作表只含开放题（教员优点 + 意见和建议），按教员/班级汇总，**不混入量表平均分**。

### 5.3 使用建议

- 汇总包导出的数字用于：教务评优、教师培训、教案调整。
- 异常答卷默认已纳入统计；只有确认是明显脏数据时，才到「明细」页剔除后再导出。
- 年度统计可跨多个周期（年表）生成，用于年终评优评教规划。

## 6. 典型月度操作流程

```
1. 教务在后台新建本月周期（选教员 + 班级 + 课程，填起止时间，立即开始）
2. 核对名单（必评/选评/不参评）
3. 如需排机房场次 → 后台添加
4. 发布/调整问卷（如有变）
5. 新建周期时已填写本班 IP 段（机房网段）
6. 学生打开统一网址，按 IP 自动进入本班作答（倒计时自动提交；超时计入）
7. 结束后点「结束问卷」→ 在「汇总」查看结果
8. 月末管理员归档 → 生成快照/哈希 → 解冻需填原因
9. 月底/月初后台导出汇总包 / 年表 / ZIP
```

## 7. 常见问题

| 场景 | 处理 |
| --- | --- |
| 学生打不开问卷 | 查该周期「名单」页里本班 IP 段、查周期状态、查场次 |
| 提交失败 | 未全答 / 评分越界 / 问卷不存在 / 本设备已提交过 / 周期已结束 |
| 提交后列表显示已提交 | 正常 |
| 看板异常提示多 | 异常默认已计入，仅作提示；确认是脏数据时到「明细」页剔除 |
| 导出异常 | 查 memory_limit、max_execution_time、zip 扩展 |
| 后台打不开 | 改密后清 session 或重启 PHP-FPM |
